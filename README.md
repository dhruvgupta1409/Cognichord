# Cognichord

An interactive web app that explores how musical practice might affect the brain at a biological level.

You can adjust parameters like instrument, tempo, session length, and practice frequency to see how they influence predicted changes in neurotransmitters, neural growth factors, and brain activity patterns. The underlying models are based on published neuroscience research but are simulations, not clinical measurements.

## What's inside

- **Simulation Lab** — four interactive models covering dopamine response, neuroplasticity (BDNF), synaptic strengthening, and brainwave patterns
- **Practice Dashboard** — log your own practice sessions and track model-based estimates over time
- **Learn** — plain-language explanations of the neuroscience behind the models
- **Research** — charts generated from 5,000 simulated practice scenarios

## Running locally

```bash
npm install
npm run dev
```

## Tech

React, TypeScript, Vite, Tailwind CSS, Recharts

## Note

This is a modeling and education tool. Outputs are estimates based on simplified mathematical models, not medical or scientific measurements.
